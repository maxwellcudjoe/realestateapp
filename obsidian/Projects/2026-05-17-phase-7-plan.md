# 📦 Phase 7 — Post-viewing handoff + Rêve Bâtir invoicing

Sequels Phase 6. Two shippable units: **7A (no schema)** = post-viewing UX + proof-of-funds; **7B (schema migration)** = Rêve Bâtir invoicing + premium tier subscriptions.

## 🎯 Goals

1. **Close the post-viewing dead-zone.** After viewing CONFIRMED, give both admin and investor an obvious next action so deals don't stall silently after the in-person walkthrough.
2. **Gate viewings/offers behind proof of funds.** Stop tyre-kickers consuming admin time before they've shown they can transact.
3. **Make Rêve Bâtir's revenue lines first-class.** Three invoice types (sourcing, success, subscription), DRAFT → SENT → PAID workflow, PDF receipts, bank-transfer reference capture. No payment processor — money flows off-platform as the owner decided.
4. **Introduce a paid Premium tier** with 48-hour head start on new deals + priority in admin matching. Drives subscription revenue without locking FREE investors out entirely.

### Schema additions (7B)

```prisma
model Invoice {
  id              String   @id @default(cuid())
  invoiceNumber   String   @unique @db.NVarChar(30)   // RB-2026-0001
  userId          String
  user            User     @relation(...)
  dealId          String?
  deal            Deal?    @relation(...)
  type            String   @db.NVarChar(20)            // SOURCING | SUCCESS | SUBSCRIPTION
  amount          Decimal  @db.Decimal(12, 2)
  description     String   @db.NVarChar(500)
  status          String   @default("DRAFT") @db.NVarChar(20)  // DRAFT | SENT | PAID | VOID
  issuedAt        DateTime?
  dueAt           DateTime?
  paidAt          DateTime?
  paidReference   String?  @db.NVarChar(255)           // bank ref / cheque
  pdfBlobPath     String?  @db.NVarChar(500)
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  @@index([userId, createdAt])
  @@index([dealId])
  @@index([status, dueAt])
}

model Subscription {
  id              String   @id @default(cuid())
  userId          String   @unique
  user            User     @relation(...)
  billingPeriod   String   @default("MONTHLY") @db.NVarChar(20)  // MONTHLY | ANNUAL
  amount          Decimal  @db.Decimal(10, 2)
  startedAt       DateTime
  cancelledAt     DateTime?
  nextRenewalAt   DateTime
  @@index([nextRenewalAt])
}

// User additions
tier            String   @default("FREE") @db.NVarChar(20)   // FREE | PREMIUM
invoices        Invoice[]
subscription    Subscription?

// Deal additions
publishedAt     DateTime @default(now())   // 48h delay key
invoices        Invoice[]
```

## 📝 Dev Notes & Decisions

- **No payment processor**: regulatory simplicity. All conveyancing money flows via solicitor client accounts. Rêve Bâtir's own fees are bank-transfer-only — admin manually marks invoices PAID with bank reference.
- **Sourcing fee timing**: chosen "manual, no auto-trigger" so the owner controls when in the pipeline (some deals charge at OFFER_ACCEPTED reservation-style, some at MEMO_OF_SALE when committed, some never). Schema doesn't need to know.
- **Success fee on COMPLETED**: auto-prompt only — admin still confirms amount and clicks Send. Default amount = `Deal.askingPrice × REVE_BATIR_SUCCESS_FEE_PCT` (use askingPrice since Offer.amount may differ from final agreed price; admin can override).
- **Uniform pricing**: no `InvestorProfile.customRates` table. Env vars for the defaults. If white-glove deals come up, admin can edit any individual invoice — flexibility lives in the invoice row, not config.
- **48h preview**: applied as a query filter, not a separate model. `where: { publishedAt: { lte: tier === 'PREMIUM' ? now : new Date(now - 48h) } }`. Works retroactively for existing deals (they get publishedAt = createdAt by default).
- **Manual renewal**: Azure SWA cron requires Azure Functions setup which we don't have. Manual button is fine for early scale; can add Functions cron later if subscriber count grows.
- **PDF library choice TBD**: lean toward `@react-pdf/renderer` (no headless browser dependency, smaller bundle, works in serverless). Will evaluate during 7.3c.
- **PoF freshness**: 6 months (UK MLR is 3 months for some uses; we're cautious without being burdensome).
